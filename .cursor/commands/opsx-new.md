Start a new change using the step-by-step artifact approach.

Creates a change directory and shows you the first artifact template. You control the pace — one artifact at a time, with review at each step.

**Input**: The argument after `/opsx-new` is the change name (kebab-case), OR a description of what you want to build.

For faster artifact creation (all at once), use `/opsx-ff` instead.
