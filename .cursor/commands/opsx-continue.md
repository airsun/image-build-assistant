Continue working on a change by creating the next artifact.

Picks up where you left off — finds the next ready artifact and creates it. One artifact per invocation.

**Input**: Optionally specify a change name (e.g., `/opsx-continue add-auth`). If omitted, prompts for selection from active changes.
